# Kynex — Digital Studio

موقع Kynex الرقمي: React + Vite + Tailwind CSS، بدعم كامل للغتين العربية والإنجليزية (نصوص حقيقية لكل لغة، وليس ترجمة آلية). الموقع بتصميم واحد ثابت (داكن، بالأزرق الليلي والذهبي) بدون خيار تبديل وضع فاتح/داكن.

## التشغيل محليًا

```bash
npm install
npm run dev
```

يفتح على `http://localhost:5173`. للبناء النهائي:

```bash
npm run build
npm run preview
```

## أين تُعدَّل الأشياء

- **النصوص (عربي/إنجليزي):** `src/data/content.js` — كل نص في الموقع موجود هنا بالكامل لكل لغة، عدّل مباشرة.
- **المشاريع:** `src/data/projects.js` — مشروع Nova موجود كنموذج أول (مقهى NOVA، بصورة حقيقية ورابط فعلي). البطاقات تُعرض بجانب بعضها في شبكة تتّسع تلقائيًا كل ما أضفت مشروعًا جديدًا — بدون أي تعديل تصميم إضافي. لإضافة مشروع جديد:
  1. انسخ الكائن الخاص بـ Nova بالكامل وعدّل القيم (`id`, `name`, `year`, `tags`، والـ`tagline` و`role` بالعربي والإنجليزي).
  2. ضع صورة المشروع داخل `public/images/work/` (مثلاً `project-name.jpg`)، ثم اكتب مسارها في الحقل `image`، مثل: `image: '/images/work/project-name.jpg'`. إذا تركت `image: null` يظهر بدلها غلاف بتدرّج ذهبي تلقائي.
  3. لرابط الموقع الفعلي للمشروع: عدّل الحقل `link`، مثل: `link: 'https://example.com'`. إذا تركته `null` لا يظهر زر "زيارة الموقع" في تلك البطاقة.
  4. أضف الكائن الجديد إلى المصفوفة `projects`. يظهر تلقائيًا في الشبكة، وبطاقة "مشاريع أخرى في الطريق" تبقى دائمًا آخر بطاقة.
- **بيانات التواصل:** داخل `content.js` تحت `contact.details` (البريد وواتساب). البريد الحالي `kynexstudio777@gmail.com` ورقم واتساب `+213 77472361` — ونموذج التواصل في الموقع يرسل الرسالة مباشرة عبر واتساب لنفس الرقم. الموقع الجغرافي محدد حاليًا كـ"يُحدَّد لاحقًا"، عدّله متى توفّر.
- **الألوان والخطوط:** `tailwind.config.js` (الألوان: `navy`, `gold`, `ivory`) و `src/index.css` (الخطوط حسب اللغة).
- **الشعار:** `src/components/ui/Mark.jsx` (العلامة الذهبية) و `src/components/ui/Logo.jsx` (شعار KYNE الكامل).

## اللغة والاتجاه

اللغة الافتراضية عربية (RTL)، مع إمكانية التبديل للإنجليزية (LTR) من الزر في الشريط العلوي. كل نص في الموقع مكتوب بشكل مستقل وصحيح لغويًا في كلا اللغتين — وليس ترجمة حرفية من واحدة للأخرى. يتم حفظ اختيار اللغة في المتصفح.

## النشر

الناتج من `npm run build` هو مجلد `dist/` ثابت (Static)، يمكن رفعه مباشرة على أي استضافة (Vercel, Netlify, Cloudflare Pages, أو أي استضافة عادية).
